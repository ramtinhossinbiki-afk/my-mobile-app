RAM HUB Mobile
==============

این پروژه یک اپ اندرویدی ساده برای RAM HUB است.
اپ فقط سایت RAM HUB را داخل WebView باز می‌کند و محتوای سایت از همان وب‌سایت لود می‌شود.

URL:
https://ramtinhosseinbiki-afk.github.io/RAM-HUB/

روش اجرا:
1. Android Studio را نصب کن.
2. این پوشه را با Open باز کن.
3. صبر کن Gradle پروژه را Sync کند.
4. یک گوشی اندرویدی یا Emulator انتخاب کن.
5. Run را بزن.

برای ساخت APK:
Build > Build App Bundle(s) / APK(s) > Build APK(s)

اگر بعداً آدرس سایت عوض شد، مقدار ramHubUrl را در:
app/src/main/java/com/ramhub/mobile/MainActivity.kt
تغییر بده.
